06

iBeacon 辅助唤醒方案

规范外补充 · 降低冷启动延迟
!
iBeacon 不在 CCC 规范范围内，不参与任何安全认证。其唯一职责是：当用户进入 ~8m 范围时提前唤醒 App、预建 BLE 连接，使门把手触碰时 UWB 测距已就绪。安全性完全由 CCC SE 机制保证。
📡

iBeacon 参数配置

覆盖约 5–8m，比车辆 BLE 广播提前 2–5 秒触发

参数推荐值说明
UUID厂商自定义（128-bit，全球唯一）每品牌或每 OEM 唯一，与车辆应用绑定
Major车型 ID区分同品牌不同车型
MinorVIN 哈希低 16 位精确标识具体车辆
Measured Power（1m参考RSSI）-65 dBm出厂实测标定，影响距离估算精度
TX Power+4 dBm（约 5–8m 覆盖）覆盖车辆外轮廓即可，过大增加误触发
广播间隔100ms（iOS 最小值）兼顾功耗与唤醒响应速度

iOS — Core Location

  • 使用 CLBeaconRegion + startMonitoring
  • 系统级回调：didEnterRegion 唤醒 App
  • 无需 App 前台，低功耗
  • 最多监测 20 个区域
  • 进一步测距：startRangingBeacons

Android — AltBeacon Library

  • AltBeacon / Android Beacon Library
  • Android 8+ 需前台 Service
  • OEM 白名单（华为/小米需加白）
  • 低功耗：SLOW_FOREGROUND_T 模式
  • 可用 Companion Device Pairing（8+）

RKE-Hands-Free — 完全免触摸（v4 新增）

§19.5.9.6 · 仅 WCC3
★
RKE-Hands-Free 是 CCC v4.1.0 新增的免触摸方案。用户通过手势或语音触发，车辆以 UWB 精确测距验证位置，位置确认后直接执行（无需 AUTH0/AUTH1）。安全性完全依赖 UWB 不可中继的物理特性。
维度标准 Passive EntryRKE-Hands-Free
触发方式门把手触碰（物理）手势 / 语音（无物理接触）
SE 认证需要 AUTH0/AUTH1不需要
位置验证UWB + Passive Entry ZoneUWB + Function Qualifier 区域位图
WCC 要求WCC2 或 WCC3仅 WCC3
未定位时不执行禁止执行 Passive Entry 类动作
安全机制SE 私钥签名 + UWB 距离仅 UWB 精确测距（不可 Relay Attack）
